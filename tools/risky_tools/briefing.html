Which resources were targeted?

Group exact identities first; use parent directories for a broader view. Path roles are hypotheses from names. Variables remain unresolved; glob patterns are not expanded. Process selectors and unresolved values stay scoped to their source call. Counts are distinct calls within each group and can overlap across groups.

Related actions, in context

Calls are associated by conversation + resource + six-hour window. This shows chronology, not proven causality or authorization. Git actions share the resolved repository context; other resources retain exact identities.

A precise subject still isn’t a verified effect

What this pass adds

Full retained command inputs, the existing Go shell splitter, quote-aware literal assignments, tool workdir, in-call cd, and git -C. Copy sources and destinations, Git refs and lease flags, API resources, SQL tables and predicates, process selectors, permission modes.

Nothing from the archive is executed. Unknown values stay symbolic. The current filesystem is never used as evidence of historical state.

What it cannot establish

A command may be conditional, backgrounded, interrupted, or only partly successful. A final exit code cannot verify each target was changed. No affected-file lists, deleted bytes, credential disclosure, process ownership, backup availability, or remote visibility are inferred.

Workspace locations and branch metadata can be stale. Missing tool workdir uses a clearly labeled workspace fallback. A cd context assumes it succeeded. Arbitrary interpreter code, functions, loops, aliases and substitutions are not interpreted. A narrow Python AST experiment recognizes literal Path writes/chmod and direct SHA-256 payloads; it is not whole-program dataflow.
