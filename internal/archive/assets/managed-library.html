Add an existing library

Choose a library folder Pharos doesn’t list yet, such as one on a drive from another Mac. Pharos adds it to your libraries and switches to it.

Restore from a backup

Pharos builds and verifies a new library from a backup or a copied library folder. The backup and your other libraries are left unchanged, and capture starts paused so you can check the result.

Choose a folder that doesn’t exist yet. For a cloud backup, first download it from Settings → Backups.

Between libraries

Add a second library to copy history between libraries or deliver it from this Mac to a drive.

Copy or move history

Bring conversations from one library into another, for example to combine two Macs’ history.

Pharos verifies everything at the destination; saved views and preferences stay with each library. Both libraries close while this runs, and Pharos reopens this library when it finishes.

Capture here, deliver to a drive

For an archive on an external drive. While the drive is away, Pharos keeps capturing into a library on this Mac; when the drive returns, it moves that history into the archive and empties the local library.

Choose sources in the capturing library first. Source access is never copied between libraries.

Where Pharos.app runs

Run Pharos from Applications to capture whenever this Mac is on. Or keep Pharos.app on a drive and open that copy on each Mac; nothing captures while that drive is unplugged. To move the app, quit it, drag Pharos.app in Finder, then reopen it.
